Về bản thân tôi

Hiện tại, tôi đang là sinh viên năm nhất chuyên ngành Công nghệ Thông tin tại trường [Tên trường Đại học/Cao đẳng của bạn]. Tôi bắt đầu tiếp cận với thế giới Web thông qua các ngôn ngữ nền tảng như HTML5, CSS3 và JavaScript.

Mục tiêu ngắn hạn của tôi là nắm vững tư duy xây dựng giao diện chuẩn ngữ nghĩa (Semantic HTML), thiết kế giao diện thích ứng đa màn hình (Responsive Design) và làm chủ hệ thống bố cục thuần CSS (Flexbox & Grid).

"Học lập trình không chỉ là ghi nhớ cú pháp, mà là rèn luyện khả năng giải quyết vấn đề, chấp nhận sai sót để hoàn thiện mỗi ngày."
— Phương châm học tập của tôi

Kỹ năng chuyên môn & Công cụ

Frontend Nền tảng

  • HTML5: Semantic tags, biểu mẫu (Forms), SEO cơ bản, chuẩn Accessibility.
  • CSS3: Box Model, Flexbox cơ bản, CSS Variables, Typography.
  • JavaScript: Cú pháp ES6+, thao tác cơ bản với DOM, xử lý sự kiện.

Công cụ & Quy trình

  • IDE / Editor: Visual Studio Code (Live Server, Extensions).
  • Quản lý phiên bản: Git cơ bản (init, commit, branch) & GitHub.
  • AI-Assisted: Prompt engineering, tra cứu tài liệu với AI và kiểm chứng code.

Kỹ năng mềm

  • Tư duy giải quyết vấn đề và tự gỡ lỗi (Debugging).
  • Khả năng đọc hiểu tài liệu kỹ thuật tiếng Anh.
  • Kỹ năng ghi chép và tài liệu hóa quá trình học (Documentation).

Tiến trình học tập kỹ thuật (Dữ liệu minh họa thực hành):

HTML5 Semantic & Cấu trúc Web 85%
CSS3 Layout (Flexbox & Grid, Responsive) 80%
JavaScript Nền tảng (DOM Manipulation & Events) 65%
Git & GitHub (Version Control Workflow) 75%
