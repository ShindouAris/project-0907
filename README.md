# Personal Developer Portfolio 🌐

Dự án website cá nhân dành cho sinh viên ngành Công nghệ Thông tin, được xây dựng xuyên suốt **5 tuần** trong học phần **Thiết kế Web** theo phương pháp **AI-Assisted Development** (Phát triển phần mềm có sự trợ giúp của AI).

---

## 🎯 1. Mục tiêu dự án

- **Xây dựng thương hiệu cá nhân:** Giới thiệu bản thân, kỹ năng kỹ thuật, sở thích và các dự án đã thực hiện trong quá trình học đại học.
- **Làm chủ công nghệ Web nền tảng:** Sử dụng thành thạo HTML5, CSS3 và JavaScript thuần (Vanilla JS) mà không phụ thuộc vào framework phức tạp ở giai đoạn đầu.
- **Rèn luyện kỹ năng AI-Assisted:** Học cách tương tác, đặt câu hỏi (prompt engineering), kiểm chứng mã nguồn do AI hỗ trợ và ghi chép nhật ký phát triển (`prompt_log.md`).
- **Quản lý mã nguồn chuyên nghiệp:** Sử dụng Git và GitHub để quản lý phiên bản, làm việc có hệ thống và chuẩn bị portfolio tuyển dụng sau này.

---

## 🛠️ 2. Công nghệ sử dụng

- **HTML5:** Xây dựng khung cấu trúc và ngữ nghĩa trang web (Semantic Tags).
- **CSS3:** Định kiểu giao diện, màu sắc, bố cục Flexbox/Grid và responsive.
- **JavaScript (ES6+):** Xử lý tương tác động trên trình duyệt.
- **Công cụ hỗ trợ:**
  - **VS Code:** Trình soạn thảo mã nguồn chính.
  - **Git & GitHub:** Quản lý phiên bản và lưu trữ kho mã nguồn từ xa.
  - **AI Assistant:** Trợ lý hỗ trợ tư vấn cấu trúc, giải thích code và rà soát lỗi.

---

## 📁 3. Cấu trúc thư mục

```text
portfolio/
├── index.html           # Trang chủ - giao diện chính của website
├── README.md            # Tài liệu giới thiệu và hướng dẫn dự án
├── prompt_log.md        # Nhật ký lưu trữ các câu lệnh làm việc với AI
├── .gitignore           # Danh sách các file/thư mục không đưa lên Git
├── css/
│   └── style.css        # Bảng kiểu dáng CSS của website
├── js/
│   └── main.js          # Mã nguồn JavaScript xử lý tương tác
└── assets/
    ├── images/          # Thư mục chứa hình ảnh (avatar, ảnh dự án...)
    └── icons/           # Thư mục chứa biểu tượng, icon mạng xã hội
```

## 🚀 4. Hướng dẫn chạy dự án

Bạn không cần cài đặt server hay công cụ phức tạp:

### Cách 1: Mở trực tiếp bằng trình duyệt (Nhanh nhất)
1. Mở thư mục `portfolio` trên máy tính của bạn (đường dẫn: `D:\portfolio`).
2. Nhấp đúp chuột vào file `index.html` (hoặc chuột phải chọn **Open with** -> chọn trình duyệt như **Google Chrome**, **Microsoft Edge**, hoặc **Brave**).

### Cách 2: Sử dụng Extension "Live Server" trên VS Code (Khuyên dùng)
1. Mở thư mục `portfolio` bằng VS Code (`File` -> `Open Folder...` -> chọn `D:\portfolio`).
2. Cài đặt tiện ích mở rộng **Live Server** (do Ritwick Dey phát triển) trong mục Extensions (phím tắt `Ctrl + Shift + X`).
3. Chuột phải vào file `index.html` và chọn **Open with Live Server** (hoặc bấm nút **Go Live** ở góc dưới bên phải màn hình).

## 📅 5. Lộ trình phát triển 5 tuần

- **Tuần 1 (Hiện tại):** Khởi tạo cấu trúc dự án, thiết lập môi trường, thiết lập Git và trang HTML kiểm tra tối thiểu.
- **Tuần 2:** Xây dựng cấu trúc HTML hoàn chỉnh và nội dung ngữ nghĩa (Header, About Me, Skills, Projects, Contact).
- **Tuần 3:** Định dạng giao diện với CSS3 (Bố cục, màu sắc, Typography, Flexbox/Grid).
- **Tuần 4:** Responsive Design (tương thích máy tính, máy tính bảng, điện thoại) và tinh chỉnh hiệu ứng chuyển động.
- **Tuần 5:** Tích hợp JavaScript xử lý tương tác, tối ưu hóa hiệu năng, triển khai trực tuyến lên GitHub Pages.
